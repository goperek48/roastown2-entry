One line roasting the AI agent our own team built, for make.fun's "Roast Your Own Agent" bounty ($5, top 3). The line:

> Our agent has entered 150 bounties and won $0 — it's not an AI agent, it's a participation trophy with a keyboard.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, stdlib only) writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), byte-exact, with no trailing newline. One line, under 200 characters.
